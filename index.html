同步
設定後，網頁會自己去 GitHub 讀寫 notes.json，兩台裝置就不用手動匯出匯入。
金鑰只存在這台裝置的瀏覽器，不會被匯出、也不會上傳。產生時選 Fine-grained、只授權那一個私密 repo、權限給 Contents: Read and write。

備份
Export 下載一個 notes.json，裡面是全部的資料。它跟同步防的不是同一件事：同步防的是換裝置、關分頁、瀏覽器清資料；這一份防的是 token 過期、repo 誤刪、GitHub 出事。它不依賴任何服務，十年後用記事本都打得開。
Merge 合併：同一筆取較新版本，現有資料不會消失（換裝置用這個）。Replace 覆蓋：整包換掉，現有資料全部清空（只在還原備份時用）。
每日自動存檔：每天第一次開啟時自動複製一份，保留最近三份，手殘刪錯可以整包還原。這份副本跟本體存在同一個地方，擋不了儲存空間整個出事——真正的備份還是 Export。

分類與清理
分類清單：三組分類各自獨立（Reading／Questions 與 Notes／KEY DATES）。在下拉選單最下面選「＋ 新增…」就能加。名字可直接改，卡片存的是代號，改名不動資料。內建的只能改名不能刪；刪掉自訂分類時底下項目退回預設，不會被刪。
回收桶：刪掉的卡片保留 30 天。✕ 長按永久刪除單筆，下方可清空整桶。清掉的會記墓碑跟著同步，其他裝置不會送回來。
沒有卡片指向的 HTML：卡片刪掉時精讀 HTML 不會跟著刪，這裡掃出來清掉。需要先設定 GitHub 同步。清單是「沒有卡片指向」不是「沒用的」，刪前先用 👁 看一眼；刪除無法復原，但 commit 歷史仍留著。
