匯出會下載一個 notes.json，裡面是全部的資料。
它跟 GitHub 同步防的不是同一件事：同步防的是換裝置、關分頁、瀏覽器清資料；這一份防的是 token 過期、repo 誤刪、GitHub 出事。它不依賴任何服務，存到硬碟或雲端硬碟，十年後用記事本都打得開。

Merge 合併：同一筆取較新版本，現有資料不會消失（換裝置用這個）。Replace 覆蓋：整包換掉，現有資料全部清空（只在還原備份時用）。

自動存檔
每天第一次開啟時，系統會把當下的所有資料複製一份存起來，保留最近三份。手殘刪錯東西時可以整包還原。
注意：這份副本跟本體存在同一個地方，擋不了儲存空間整個出事——真正的備份還是上面的 Export。
